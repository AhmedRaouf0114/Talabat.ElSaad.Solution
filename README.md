# Talabat E-Commerce API

A scalable e-commerce backend built with ASP.NET Core Web API following Clean Architecture principles.

## Features

- Authentication & Authorization
- Product Management
- Basket Management
- Order Management
- Filtering
- Sorting
- Searching
- Pagination

## Technologies

- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Redis
- JWT Authentication
- AutoMapper
- Swagger
- Clean Architecture
- Repository Pattern
- Unit Of Work
- Specification Pattern
